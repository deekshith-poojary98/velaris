# velaris-contracts

Versioned capability Protocols for Velaris.

| Contract | Module | Used by runner |
|----------|--------|----------------|
| `api@0.1` | `velaris_contracts.api.v0_1` | Yes |
| `browser@0.1` | `velaris_contracts.browser.v0_1` | Yes |
| `secrets@0.1` | `velaris_contracts.secrets.v0_1` | Yes |
| `target_environment@0.1` | `velaris_contracts.target_environment.v0_1` | Config merge only |

No runtime dependencies. Import Protocols for typing and provider compliance.

## Install

```bash
pip install -e .
```
